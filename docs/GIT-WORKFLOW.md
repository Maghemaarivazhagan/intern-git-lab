\# Git Workflow



\## Basic Workflow



1\. Check the current repository status.

2\. Create or switch to a working branch.

3\. Make the required changes.

4\. Review changes using `git diff`.

5\. Stage selected changes using `git add`.

6\. Create a meaningful commit.

7\. Push the branch to the remote repository.

8\. Open a Pull Request.

9\. Review and merge the Pull Request.



\## Core Lifecycle



Working Directory

→ Staging Area

→ Local Repository

→ Remote Repository
